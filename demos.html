Demos

Nine small programs, all plain VB6.

Three demoscene intros, built by agents driving the running IDE through its automation tools and compiled by the real VB6 compiler. Three ordinary form programs that run under F5 and build with the same compiler. And three that exist to be checked rather than watched.

Every one is plain VB6 source in the repository. The built programs are deliberately not committed: each ships as source you rebuild rather than a binary you trust.

  • Intros
  • Form programs
  • Checks

Intros

The sort of thing that used to arrive on a floppy with a scroller and a chiptune.

neon-aurora

A six-part Amiga-style intro: raster plasma, copper bars, a 3D starfield, a glenz vector, vector balls and a sine-scroller, with MIDI chiptune music underneath.

The plasma is computed per pixel into a 32-bit bitmap and blitted with StretchBlt; the music goes out through midiOutShort. Both are Windows API calls, in VB6, written by an agent.

  • 6 classes
  • 2 modules
  • 1 form
  • Built by vb6.exe

neon-vertigo

130 vector balls over a sphere on a Fibonacci lattice, spun on two axes through a pair of rotation matrices, projected with perspective, depth-shaded from magenta to blue and painted back to front.

  • 1 form
  • Built by vb6.exe

wild-ecstasy

“HEXIDE” on a per-character sine wave, colours cycling through the spectrum. The smallest thing here, a form and a class of about a hundred lines together, and the best one to read first.

  • 1 class
  • 1 form
  • Built by vb6.exe

Form programs

Written the way a VB6 developer writes them. Each runs under F5 in HexIDE and builds with vb6.exe.

notepad-forms

Windows' Notepad on forms. Two TextBoxes swapped by Word Wrap, a CommonDialog for Open, Save As and Font, Line Input # and Print #, a modeless Find dialog, the Clipboard object, and a save prompt in QueryUnload.

  • 2 forms
  • Runs under F5
  • Built by vb6.exe

minesweeper-forms

Windows' Minesweeper on a form. A Label field loaded at run time, right-click flags through MouseDown's Button, a recursive flood fill over a 2-D array, a Timer clock, and a face that starts again.

  • 1 form
  • Runs under F5
  • Built by vb6.exe

battleship-forms

The Battleship engine below, played on forms: a modal setup dialog, a Label grid loaded at run time, WithEvents, MouseDown, and Play again.

  • 3 classes
  • 1 module
  • 2 forms
  • Runs under F5
  • Built by vb6.exe

Checks

Not for watching. Each one is here because it proves something, or once caught something a test suite missed.

AllSunk=False

battleship

An object-oriented Battleship engine: four classes, properties, an object array holding the fleet, and WithEvents raising the hits, with no graphics at all.

It exists to be run twice: on HexIDE's interpreter as a regression test, and inside a native executable built by the real VB6 compiler. That trace is what both of them produce, line for line. A tree-walking interpreter and the real compiler agreeing exactly is the difference between “we implemented VB6” and “we checked”.

  • 4 classes
  • 1 module
  • No forms

bill-of-fare

A tour of the VB6 menu surface: a menu bar, submenus nested two deep, separators, shortcuts that fire from anywhere, access keys, a disabled item, and click dispatch. Bill of fare is the old word for a menu.

Every element in that screenshot was broken at some point, and each shipped under a green test suite. Each was found by a person opening the menu and looking at it.

  • 1 form
  • 16 menu items
  • 3 separators
  • 5 shortcuts

spring-tide

A short module to open with an outside language server attached, so you can see that server's folding regions and diagnostics drawn in HexIDE's editor. The colouring is HexIDE's own; the fold markers and the squiggle come from the server.

It doesn't build, by design: the last line is a deliberate syntax error, because a diagnostic is half of what it is here to show.

  • 1 module
  • Doesn't build

Read the source

All nine are in the repository.

Each lives in its own folder with its complete VB6 source and a README explaining how it works. With VB6 installed, rebuild any but spring-tide with VB6.EXE /make.
