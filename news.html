Release23 November 2026

HexIDE 0.7.0: VBA from Office documents, programs that draw, and projects that target RDCore

0.7.0 is the fourth weekly release: about 400 changes in the week since 0.6.0.

Office and VBA7

Open an Excel, Word or PowerPoint document beside your workspace and browse its VBA project: the host objects, modules, references and decoded source, with a notice that Office may run different compiled code. It is read-only. A locked project keeps its code hidden, a UserForm opens its code while its designer is still to come, and the document can't be run or written back. Its code tabs attach language servers, read-only, and their findings are underlined.

A VBA7 project's bitness belongs to the project. A 32-bit project runs, with LongPtr as a Long and VBA7's own #If constants. With VbaBitness=64 in a trailing [HexIDE] section of its project file, a project is 64-bit: LongLong and a 64-bit LongPtr run with the arithmetic and overflow Excel x64 was measured giving, active declarations need PtrSafe, and on macOS it takes Excel for Mac's constants. VB6 projects keep VB6's rules.

Running

Forms and PictureBoxes draw. Line, PSet, Circle and Cls paint the pixels VB6 was measured painting, and Point reads them back, through each one's own coordinate system, which Scale and ScaleMode set. Thick lines, arcs and sectors still stop with a message naming what's missing.

GoSub, Return, and computed On GoTo and On GoSub run. Fixed-length Strings work in variables, arrays, Type fields and file records. PropertyBag keeps VB6's own bytes, LSet copies between Types, an array declared As New makes each element on first use, and IRR, MIRR and DDB run. MSFlexGrid and MSComctlLib's Slider run as in-box controls, and a ListBox shows checkboxes and columns. Buttons and lists raise KeyDown, KeyPress and KeyUp, a form's Default and Cancel buttons take Enter and Esc, and LoadPicture reads JPEG and GIF. 40 of the language's names still stop a program, down from 76.

Projects that target RDCore

A project with Targets=RDCore in its [HexIDE] section uses RDCore's predefined #If constants when it runs and when the code window greys out inactive code. Such a project, or one opened as an .rdproj, reads PNG pictures with LoadPicture, and its Images, Labels and PictureBoxes take RDCore's Opacity. VB6 and VBA projects are unchanged.

When one project of a group references another, the .rdproj HexIDE writes for RDCore names it, so RDCore binds its classes; this needs RDCore.SDK 0.1.9-alpha or later. RDCore's rename and references commands now come from its add-in, and the documents of an add-in's project type go only to that add-in's language servers. RDCore's option to set Win64 only on Windows is now one setting for the whole IDE, in Options → Environment → General.

The editor and language servers

While a program is paused, a language server that offers them shows values beside the code, for HexIDE's own runs and for an outside debug adapter. Linked editing, off by default under Options → Editor, renames a variable's other uses as you type. Type Hierarchy joins Call Hierarchy, and the Refactor and Source Actions menus ask the server what it can do at the caret, without needing a diagnostic. Servers that offer it report on modules you haven't opened, in the Diagnostics window. List members as you type can be turned off.

A project's .vbp can be edited as text from Project Explorer, with undo, and saved back into the project. A file opened from a twinBASIC project archive now reaches language servers.

Builds under another name, and add-ins

A repacked Windows setup program carries the brand's logo, name and links. A branded product's dialogs show its icon, its macOS app menu and Dock use its name, and it can name its own project-local state folder. A program with no icon of its own, run or made in HexIDE, now shows a neutral window icon rather than HexIDE's mark.

VB6's own projects now open through a project type, registered the way an add-in registers one. An add-in's project type can use VB6's form format for its forms, UserControls and PropertyPages, and F5 runs an add-in project with that add-in's launch by default. Add-ins can handle their own language servers' commands, open a document at a range, and report a failure that shows in Options → Add-ins. A language server can give AI Chat tools, and a tool asks before it runs unless it says it only reads. Add-in revocation now works: the list HexIDE ships, and the one this site serves, are signed with the HexIDE root.

Everything else

  • macOS shows a running form's menus in the menu bar, and the app menu opens HexIDE's own About.
  • The Menu Editor opens with a form's existing menus, makes menu control arrays, offers the full shortcut list, and works from the keyboard.
  • The Font dialog offers Strikeout and Underline, and controls draw both.
  • Add Watch offers (All Modules), as VB6 does, with Module and Procedure pickers.
  • Saving: Save As, Make and Make with VB6 ask before replacing an existing file.
  • Windows can sign out, shut down or restart with HexIDE open.
  • Context menus no longer cut off their shortcuts the first time they open.
Before you upgrade
  • Add-ins signed under the new HexIDE root still show as unsigned in this build. The fix follows as a point release this week.
  • Before the first run in a session, HexIDE asks if any of the project's code came from a file Windows marks as downloaded, a file macOS quarantines, or an Office document. It names each file, No is the default, and a Yes holds for the session.
  • AI Chat's first message to an endpoint that isn't on this computer waits for Send on its privacy notice.
  • A project's Win64OnlySetOnWindows line is now ignored, and kept when it saves. Set the option in Options → Environment → General instead.
  • A brand.json writes its logo paths with /.

Still missing

Third-party controls at run time, COM and Declare calls, MDI forms, printing, and autosave. The Scope page has the whole list.

Release16 November 2026

HexIDE 0.6.0: shortcuts you can remap, high-contrast themes, and builds under another name

0.6.0 is the third weekly release: about 230 changes in the week since 0.5.0.

The workbench

In Options, the Keymap page remaps any command's shortcut. Search for a command and press the keys you want, and any command that already uses them is named before you confirm. Your changes can be exported and imported, and they survive a change of keymap or profile. The Editor Formatting page sets each token's colours, the editor's font and its size, with a preview, and keeps them with each theme.

High-contrast light and dark themes are in Options in every profile, with heavy borders on whatever has focus or is selected. HexIDE switches to them when Windows or macOS asks for high contrast; Linux waits on support in the UI toolkit. Split, in the Window menu, shows two panes over one code document, each with its own scroll position, caret and selection. A tool window you float now opens in a window of its own, and floating windows come back where they were after a restart.

Running

LoadResString, LoadResData and LoadResPicture read a project's resource file, and NPV runs with vb6.exe's precision in the cases measured. A class's default member is read where a value is wanted, a Type field can hold an object, and Dim n As Node and the other common-controls classes work without their library's name. Switching between forms raises LostFocus, Deactivate, Activate and GotFocus in VB6's order, a ListBox raises Scroll, and MsgBox honours vbMsgBoxRight and vbMsgBoxRtlReading. On Windows, a program's dates follow Windows' own locale data. 76 of the language's names still stop a program, down from 82.

A breakpoint's condition now decides whether F5 stops there. A made program draws VB6's system colours: before this, a form left at its default colours came out pink.

Language servers

A language server can format as you type: on Enter it can indent the new line and close the block, and its edits undo with the keystroke. Completion takes snippets, with nested placeholders and the protocol's snippet variables. Files a project carries, such as Markdown or C, get completion and signature help from the server attached for them. The Language & Debug Servers window, in the Tools menu, adds and edits server entries in a form, and restarts one server without restarting HexIDE. Servers can also be reached over TCP, in either direction, and can watch files.

For RDCore's language server, the rdcore provider now writes the .rdproj format RDCore reads, naming the project's .vbp, and its documented entry restarts the server as projects join or leave a group. The language-servers guide has its entry, under RDCore.

Builds under another name

A brand.json beside the executable makes an installation another product. Its name, logo, tagline, links and added credits appear in the title bar, dialogs, menus, About and --help, and it keeps its own settings, logs and recovery files. It can choose a default profile and translate its tagline and credits. HexIDE's own credits and licence notice stay. HexIDE.Repack, run from a clone of the release's tag, turns a published Windows, macOS or Linux build into that product, with its own executable or app bundle and icons. Its output is unsigned, and whoever makes it signs it. The white-label guide has the details.

Add-ins

An add-in can now supply a project type that reads and writes its own project file, adds and removes members, and carries forms, UserControls and PropertyPages, which it saves if it can also write them. No add-in uses this yet. An add-in's pane titles, menu items and commands can follow the IDE's language, and every label is checked before it's shown. Each package is checked again just before it loads, and one that changed on disk since is refused.

Everything else

  • Open HexIDE Log Folder, in the Help menu, opens the folder of logs, and the bug-report form says what a log attached to a public issue can show.
  • Project groups save in VB6's own format.
  • Saving never replaces a project file another program has changed without asking first.
  • Esc cancels every dialog that has a Cancel button, and dialog titles follow the IDE's language.
  • The Properties window shows the properties HexIDE doesn't model, greyed and read-only.
  • Project Explorer opens a project's own file as read-only text.
  • Linux can run on Wayland directly with --platform wayland or --platform auto. X11 stays the default.
  • AI Chat follows the IDE's language, and stops before reading or sending anything to a remote endpoint that has no API key.
Before you upgrade
  • In the code window, Ctrl+Y deletes the current line. Redo is Ctrl+Shift+Z.
  • A module or class whose Attribute VB_Name differs from its line in the .vbp now loads under the file's name, and Save Project writes that name into the .vbp.
  • A compiled add-in that calls RegisterComponent or RegisterProjectTemplate must be rebuilt against this release.
  • The first time a context menu opens, it can cut off its shortcuts and submenu arrows.

Still missing

Third-party controls at run time, COM and Declare calls, MDI forms, printing, and autosave. The Scope page has the whole list.

Release9 November 2026

HexIDE 0.5.0: fourteen new languages, and projects reopen as you left them

0.5.0 is the second weekly release: about 275 changes in the week since 0.4.0.

Languages

HexIDE now ships in 39 languages and four regional variants. Fourteen languages are new: Basque, Bulgarian, Catalan, Croatian, Estonian, Galician, Hungarian, Latvian, Lithuanian, Romanian, Serbian in Latin script, Slovak, Slovenian and Thai. Canadian French, Mexican Spanish and Brazilian Portuguese are new regional variants.

The workbench

A project reopens with the editors and designers you had open when you closed it, in the same tab order and with the same document active. Panel Layouts in the Window menu saves an arrangement under a name and switches between them, and Full Editor gives documents the whole frame.

Running

VB code now runs on a 64 MiB stack on Windows and Linux. Measured in a Debug build on Windows, a recursive Function gets about 1,490 calls deep before the stack runs out and raises Error 28, up from about 31. macOS keeps its 8 MiB stack. Whatever the stack allows, no recursion goes past 5,000 calls, where it raises Error 28, and vb6.exe goes on to 258,825. Deep nesting no longer stops a module loading.

FlatScrollBar and Animation run, MonthView has begun, and ListView draws ImageList images in all four views. FormatNumber, FormatCurrency and FormatPercent run, with vb6.exe's rounding. A Property Get, Let or Set in a standard module is reached by its name, where a read used to give Empty with no error, and so is a class's or form's own. 82 of the language's names still stop a program, down from 85.

Language servers

With a language server that offers them, the code window now has Find References, Call Hierarchy, Go to Implementation, Go to Type Definition, Format Selection, Expand and Shrink Selection, and Quick Fixes. HexIDE's own VB6 server doesn't offer these, so they need another server. Rename can change several modules at once when a server's answer spans them, and hovers render Markdown.

Everything else

  • The Outline window lists the current document's symbols and follows the caret.
  • The Diagnostics panel, in the Tools menu, lists errors and warnings across documents.
  • Block-end hints name the block being closed, and Options can hide them.
  • The Properties window filters as you type.
  • Find and Replace remember their text and options when reopened.
  • Breakpoints can have conditions, which an external debug adapter that supports them honours. Under F5 a conditional breakpoint stops every time, and says so once per session.
  • Themes: a JSON theme pack in your themes folder loads without a rebuild.
  • Linux has 32-bit Arm builds.
Before you upgrade
  • --personality has gone. Use --profile vb6, --profile vbaode or --profile vba.
  • Hindi, Persian, Urdu, Latin and Esperanto are no longer in the download. Hindi, Persian and Urdu have moved to separate packs, which HexIDE can't install yet. A saved choice of any of the five falls back to English.
  • Some code that used to run is now refused, as vb6.exe refuses it: Public arrays, constants, fixed-length strings, user-defined-type variables and Declare statements in a class or form, a call ending in a comma, and a ReDim that changes an array's element type.
  • In a completion list, Enter accepts the selected item before starting a new line and Space accepts it before typing the space, as VB6's List Members does.

Still missing

Third-party controls at run time, COM and Declare calls, MDI forms, printing, and autosave. The Scope page has the whole list.

Release2 November 2026

HexIDE 0.4.0: the common controls run, and unsaved work survives a crash

0.4.0 is the first weekly release: about 300 changes in the week since 0.3.0.

Running

Most of Windows' common controls run now. ListView draws its four views, though not their images yet, with columns, sorting, mouse and keyboard selection, and label editing. TreeView builds, walks and edits a tree. TabStrip, SSTab, Toolbar, StatusBar and UpDown draw, raise their events and load what the designer saved, and ImageList holds the Toolbar's images. RichTextBox, DTPicker and MaskedEdBox have begun. Controls.Add and Controls.Remove run, and a control held in a WithEvents variable raises its handlers.

CallByName, Shell, CVErr, FormatDateTime, Partition, ObjPtr, StrPtr and VarPtr run, and so do the loan and depreciation functions, from Pmt to SYD, each matching vb6.exe's results. 85 of the language's names still stop a program, down from 143, and nothing stops a module loading any more.

Safety

Unsaved work survives a crash. While the IDE runs it keeps a private copy of every unsaved document, and after a crash, a kill or a power cut the next start offers it back, leaving the files on disk untouched. Saves are written to a staging file and flushed before they replace anything, so a save interrupted half way can't damage the file it was replacing.

Everything else

  • The code window takes colours from a language server's semantic tokens, colours brackets by depth, and has indent guides, sticky scroll, Recent Edits, Paste as Comment, and greyed inactive #If branches.
  • The designer previews a form without running the project, shows tab order, dims invisible controls and designs controls on SSTab pages. The Components dialog adds Windows' common control libraries to a project.
  • Windows you close can be reopened from the Window menu, or with Ctrl+Shift+T.
  • Find searches the whole project by default.
  • Language servers can import the project through a command they declare, ask for generated workspace files, and hear about files you create.
Before you upgrade
  • A new project's first save asks where each form and module goes, rather than leaving them in a temporary folder.
  • Make asks before replacing an existing project archive, and declining leaves both the archive and the program untouched.

Still missing

Third-party controls at run time, COM and Declare calls, MDI forms, printing, and autosave. The Scope page has the whole list.

Release26 October 2026

HexIDE 0.3.0: every template form saves, and F5 runs real programs

0.3.0 is a month of work: about 460 changes since 0.2.0, none of which was in a download until now. From here there is a release every Monday, so they reach you within a week rather than when somebody remembers.

Saving

All 22 of the designer files VB6 itself ships now survive a save byte for byte, up from 21, and VB6's own .vbp files round-trip with their line order and description kept. Sources are read in your machine's ANSI code page and keep their encoding, and an edit that code page can't hold is refused before anything is written.

Running

A form is a real object now. Several forms work with Load, Show, vbModal and Unload, and mouse, double-click, focus and Activate events fire. Text, Random and Binary files work, and so do Collection, Static, ReDim Preserve, named arguments, DefType, #If, Like and GetSetting. Something the interpreter can't run now stops with a message that names it, instead of carrying on. 143 of the language's names still stop a program, down from 261.

Everything else

  • Make EXE builds a program that runs on a machine with neither .NET nor HexIDE installed: one runner, with the project packed beside it, running every form and module.
  • The designer gives new controls VB6's sizes, names and tab order. A control HexIDE doesn't model, such as an ImageList, shows as a labelled box where VB6 draws it. The ProgressBar is the first in-box OCX that runs.
  • The debugger breaks on the statement when you press Debug on an unhandled error, and Debug.Assert breaks. Run, Start External Debug Session drives an outside debug adapter.
  • Language servers can connect over WebSocket, take argument lists and environment variables, and show their progress in the status bar.
  • A Windows installer for x64, optional. Like everything here, it isn't signed yet.
  • 860 strings in 30 languages, and the IDE now starts in your system's language.
Before you upgrade
  • Programs made with 0.2.0 don't start. Make them again with 0.3.0.
  • Line numbers now count from the top of the file, header included, so they agree everywhere. Add-ins and automation that use line numbers will see different ones.
  • Bookmarks and breakpoints are moved to a new place as a project opens, one way: open it in 0.2.0 again and 0.2.0 deletes them the next time it saves.
  • The downloads that need .NET installed are bigger than 0.2.0's, because the runner they carry for Make EXE now has its own copy of .NET.

Still missing

Third-party controls at run time, COM and Declare calls, MDI forms, printing, and autosave. The Scope page has the whole list.

Release24 September 2026

HexIDE 0.2.0: forms saved the way VB6 writes them

The designer writer stopped rebuilding forms in its own shape and started reproducing VB6's: 21 of the 22 template forms round-trip byte for byte, and a form HexIDE can't reproduce opens read-only rather than being rewritten.

  • Frames and PictureBoxes hold controls, and the Image control arrives.
  • Any language server can be attached through lsp-servers.json, and the Protocol Inspector shows what crossed the wire.
  • Go to Declaration, workspace symbols and code actions.
