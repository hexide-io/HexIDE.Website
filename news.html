Release26 October 2026

HexIDE 0.3.0: every template form saves, and F5 runs real programs

0.3.0 is a month of work: about 460 changes since 0.2.0, none of which was in a download until now. From here there is a release every Monday, so they reach you within a week rather than when somebody remembers.

Saving

All 22 of the designer files VB6 itself ships now survive a save byte for byte, up from 21, and VB6's own .vbp files round-trip with their line order and description kept. Sources are read in your machine's ANSI code page and keep their encoding, and an edit that code page can't hold is refused before anything is written.

Running

A form is a real object now. Several forms work with Load, Show, vbModal and Unload, and mouse, double-click, focus and Activate events fire. Text, Random and Binary files work, and so do Collection, Static, ReDim Preserve, named arguments, DefType, #If, Like and GetSetting. Something the interpreter can't run now stops with a message that names it, instead of carrying on. 143 of the language's names still stop a program, down from 261.

Everything else

  • Make EXE builds a program that runs on a machine with neither .NET nor HexIDE installed: one runner, with the project packed beside it, running every form and module.
  • The designer gives new controls VB6's sizes, names and tab order. A control HexIDE doesn't model, such as an ImageList, shows as a labelled box where VB6 draws it. The ProgressBar is the first in-box OCX that runs.
  • The debugger breaks on the statement when you press Debug on an unhandled error, and Debug.Assert breaks. Run, Start External Debug Session drives an outside debug adapter.
  • Language servers can connect over WebSocket, take argument lists and environment variables, and show their progress in the status bar.
  • A Windows installer for x64, optional. Like everything here, it isn't signed yet.
  • 860 strings in 30 languages, and the IDE now starts in your system's language.
Before you upgrade
  • Programs made with 0.2.0 don't start. Make them again with 0.3.0.
  • Line numbers now count from the top of the file, header included, so they agree everywhere. Add-ins and automation that use line numbers will see different ones.
  • Bookmarks and breakpoints are moved to a new place as a project opens, one way: open it in 0.2.0 again and 0.2.0 deletes them the next time it saves.
  • The downloads that need .NET installed are bigger than 0.2.0's, because the runner they carry for Make EXE now has its own copy of .NET.

Still missing

Third-party controls at run time, COM and Declare calls, MDI forms, printing, and autosave. The Scope page has the whole list.

Release24 September 2026

HexIDE 0.2.0: forms saved the way VB6 writes them

The designer writer stopped rebuilding forms in its own shape and started reproducing VB6's: 21 of the 22 template forms round-trip byte for byte, and a form HexIDE can't reproduce opens read-only rather than being rewritten.

  • Frames and PictureBoxes hold controls, and the Image control arrives.
  • Any language server can be attached through lsp-servers.json, and the Protocol Inspector shows what crossed the wire.
  • Go to Declaration, workspace symbols and code actions.
